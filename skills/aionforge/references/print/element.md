# 核心图标与左胸徽章

左胸小印花不是「整张印花缩小」，而是从印花里挑**一枚**能独立成立的图标。背面主印花配左胸徽章时，用这里的规则。

## 选图标

优先顺序：

1. 独立图形 / 图标 / 符号（靶心、箭头、动物头、徽章、花朵主体）。
2. 图形主体的一部分，但必须轮廓闭合、缩小后仍能辨认。
3. 整张印花（只在用户明确同意时；不推荐，细节会糊）。

不要选：

- 一整行文字、标点、装饰星点。
- 与文字粘连、拆开就缺笔画的图形。
- 贴到画布边缘、可能被裁断的元素。

## 提取

用 `extract-core-element`，输入原始印花稿（白底或透明底均可），`--element-hint` 用 10–25 字点名词图标，例如「箭头靶心图标」「熊头线稿」「小花主体」。不要写坐标。

门槛：

- `complete: true`，且 `margin_ratio ≥ 0.02`。
- 图标里没有带进文字、装饰或背景色块。
- 输出是 RGBA 透明底。

`complete: false` 时先改 hint 重跑一次；仍失败就问用户换稿或跳过徽章。**不要**改用本地 alpha 连通域碎片拼一个图标；也不要在模型不可用时静默回落。

## 徽章可读性

对提取出的图标跑 `print metrics`：

- 主色 ≤ 2 时最稳；超过 2 色用 `print adapt --strategy palette` 收到 2 色。
- `mean_stroke_ratio` 太小（缩到 12% 衣宽后等效笔画 < 1.5px）时，用 `outline` 或换更粗的图标。
- 圆角、细线、渐变在缩小后容易消失；必要时用 `palette` 简化。

## 位置

- `region: "left_chest"`，默认 `x=0.32, y=0.28, width=0.12`。
- 以用户确认为准；不同版型的左胸位置会变。
- 徽章只出现在正面；背面只放主印花。

## 无图标时

问用户三选一：

1. 跳过左胸徽章（只做背面主印花）。
2. 整张印花缩小（明确告知细节会糊）。
3. 换一张有独立图标的稿。
