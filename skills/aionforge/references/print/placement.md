# 正反面与位置尺寸规范

先看印花，再看指标，最后按固定位置规范给建议表让用户确认。**指标只作证据，不做结论。**

## 固定位置与尺寸规范（行业标准，必选）

参考成人团体服 / T 恤印 logo 尺寸规范（以平铺含袖 T 恤实拍画布、成衣躯干净宽 ≈ 52cm / 占画布 ~0.50 为基准）。**所有常规 T 恤一律直接锁定下列标准预设，禁止凭感觉随意填写坐标或宽度**：

| `region` 预设 | 适用面 | 成人实物尺寸 | 参考线基准 | 固定画布参数 |
| --- | --- | --- | --- | --- |
| `left_chest`（左胸小标） | `front`（穿着者左胸 = 正面图右侧） | `8–12cm × 8–12cm`（推荐 ~9.5cm） | 距左肩缝 `5.5–8cm`，距中线 `4–6cm` | `x=0.61, y=0.29, width=0.09, max_height=0.11, anchor="center"` |
| `chest_center`（胸前居中） | `front`（胸前正中） | `28–32cm × 28–32cm`（推荐 ~29cm） | 距前领口下方 `7–9cm` | `x=0.50, y=0.27, width=0.28, max_height=0.32, anchor="top"` |
| `back_center`（全背印花） | `back`（后背视觉中心） | `28–32cm × 35cm`（推荐 ~31cm × 35cm） | 距后领线下 `2–5cm` | `x=0.50, y=0.19, width=0.30, max_height=0.40, anchor="top"` |
| `back_neck`（上背小标） | `back`（后领正下方） | `5–8cm × 5–8cm`（推荐 ~7cm） | 距后领缝正下方 `3–5cm` | `x=0.50, y=0.17, width=0.07, max_height=0.09, anchor="top"` |
| `hem_left` / `hem_right`（下摆标） | `front`（左/右衣角） | `5–8cm × 5–8cm`（推荐 ~6.8cm） | 距下摆缝上 `5cm` | `x=0.66`/`0.34`, `y=0.84, width=0.065, max_height=0.08, anchor="bottom"` |

- **顶边锚定与防越界**：`chest_center` 与 `back_center` 固定使用 `anchor="top"` 与 `max_height` 限制，无论印花是横幅还是竖版插画，上缘始终准确落在领口下方 7–9cm（正面）或 2–5cm（背面），高长图自动按最大高度封顶而不侵入下摆或侧缝。
- **左右胸方向铁律**：正面平铺图上看，**穿着者左胸位于画面中心线右侧（`x=0.61`）**，切勿把左胸标印到画面左侧（`x=0.32` 为右胸）。

## 正反面判断表

| 信号 | 偏正面（`chest_center`） | 偏背面（`back_center`） |
| --- | --- | --- |
| 细节密度（`edge_density`） | ≤ 0.08 | ≥ 0.15 |
| 主色数量 | ≤ 2–3 | ≥ 5 |
| 缩到正面图宽（~0.28）时的等效笔画（`mean_stroke_ratio × 0.28 × 图宽`） | ≥ 2 px | < 2 px |
| 宽高比（`aspect`） | 1.4–2.2 横幅 | ≤ 1.2 方形 / 纵向插画 |
| 构图 | 单一焦点、粗笔画 | 多元素、插画、泼墨、渐变 |
| 核心图形 | 有独立图标 | 无独立图标（只能整图） |
| 文字 | 主标题大、可缩 | 小字多、依赖大尺寸阅读 |

## 判断步骤

1. 对每张印花跑一次客观体检，拿到 `aspect` / `palette` / `edge_density` / `mean_stroke_ratio`。带水印的原始稿会污染调色板，精确判断用抠图后的透明稿。
2. 自己看图：主视觉是什么、有几层信息、文字占多大、缩到目标宽度（正面 0.28 / 背面 0.30）后还能不能读。
3. 按上表打分，写出正面 / 背面建议和 2–3 条理由。
4. 用户明确指定正反面或特殊微调时用户优先；如果指定与可读性冲突，先提示风险再执行。

## 硬规则

- **背面主印花 ⇒ 左胸必须有配套小印花**；小印花取核心图标，固定使用 `left_chest` 规范（8–12cm），不把整张印花缩小。
- 一张印花只能选一个主位置；「两面都印」必须用户明确点名。
- 没有可用核心图标时问用户：跳过徽章 / 整图缩小 / 换有独立图标的稿。
- 所有位置、宽高上限与锚点写进 `facts.print.placements[]`，不要只写在 Prompt 里。

## 常见形态

| 形态 | 建议 | 理由 |
| --- | --- | --- |
| 宽幅字标 + 小图标（如「锁定目标」） | `chest_center` 正面，或 `back_center` + `left_chest` | 横幅适合胸前；做背面时图标可单独做左胸徽章 |
| 多元素涂鸦插画（如「CHILL OUT」熊头） | `back_center` + `left_chest` | 元素多、小字多，缩到胸前会糊 |
| 纵向插画 / 大幅海报 | `back_center` + `left_chest` | 需要全背尺寸承载细节 |
| 单色粗笔画图形 | `chest_center` 或 `left_chest` | 缩小时仍可读 |
| 纯文字标语 | 正面（短）/ 背面（长） | 短标语适合胸前，长句需要更大宽度 |

## 确认话术

给用户一张表：印花 | 建议 `region` | 标准尺寸 | 理由 | 需要确认的项。明确问：

- 主印花放正面（`chest_center`）还是背面（`back_center`）？
- 放背面时，正面左胸徽章（`left_chest`）用哪个核心图标？
- 是否按行业标准固定位置与尺寸执行？
