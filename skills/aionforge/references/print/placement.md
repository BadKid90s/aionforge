# 正反面与位置判断

先看印花，再看指标，最后给建议表让用户确认。**指标只作证据，不做结论。**

## 判断表

| 信号 | 偏正面 | 偏背面 |
| --- | --- | --- |
| 细节密度（`edge_density`） | ≤ 0.08 | ≥ 0.15 |
| 主色数量 | ≤ 2–3 | ≥ 5 |
| 缩到衣宽 30% 时的等效笔画（`mean_stroke_ratio × 0.30 × 衣宽`） | ≥ 2 px | < 2 px |
| 宽高比（`aspect`） | 1.4–2.2 横幅 | ≥ 1.8 方形 / 纵向插画 |
| 构图 | 单一焦点、粗笔画 | 多元素、插画、泼墨、渐变 |
| 核心图形 | 有独立图标 | 无独立图标（只能整图） |
| 文字 | 主标题大、可缩 | 小字多、依赖大尺寸阅读 |

## 判断步骤

1. 对每张印花跑一次客观体检，拿到 `aspect` / `palette` / `edge_density` / `mean_stroke_ratio`。带水印的原始稿会污染调色板，精确判断用抠图后的透明稿。
2. 自己看图：主视觉是什么、有几层信息、文字占多大、缩到目标宽度后还能不能读。
3. 按上表打分，写出正面 / 背面建议和 2–3 条理由。
4. 用户明确指定正反面时用户优先；如果指定与可读性冲突，先提示风险再执行。

## 硬规则

- **背面主印花 ⇒ 左胸必须有配套小印花**；小印花取核心图标，不把整张印花缩小。
- 一张印花只能选一个主位置；「两面都印」必须用户明确点名。
- 没有可用核心图标时问用户：跳过徽章 / 整图缩小 / 换有独立图标的稿。
- 正面主印花默认胸前正中；背面主印花默认肩胛骨之间；左胸徽章默认左胸上方。
- 位置与宽度写进 `facts.print.placements[]`，不要只写在 Prompt 里。

## 常见形态

| 形态 | 建议 | 理由 |
| --- | --- | --- |
| 宽幅字标 + 小图标（如「锁定目标」） | 正面胸前，或背面大图 + 左胸图标 | 横幅适合胸前；做背面时图标可单独做徽章 |
| 多元素涂鸦插画（如「CHILL OUT」熊头） | 背面 | 元素多、小字多，缩到胸前会糊 |
| 纵向插画 / 大幅海报 | 背面 | 需要足够衣宽承载细节 |
| 单色粗笔画图形 | 正面或左胸 | 缩小时仍可读 |
| 纯文字标语 | 正面（短）/ 背面（长） | 短标语适合胸前，长句需要更大宽度 |

## 确认话术

给用户一张表：印花 | 建议位置 | 宽度 | 理由 | 需要确认的项。明确问：

- 主印花放正面还是背面？
- 放背面时，左胸徽章用哪个核心图标？
- 位置和宽度是否按建议？
