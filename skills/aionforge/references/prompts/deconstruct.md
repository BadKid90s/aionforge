# Prompt 模板：竞品参考图反推与视觉迁移（deconstruct）

按 `references/prompts/formula.md` 组段。把竞品/标杆参考图的版式骨架、光影色调与排版节奏迁移到用户自己的女装成衣上。写进 `<run_dir>/work/prompts/deconstruct-<序号>.txt`。

## 填写规则

1. **先判别参考图类型**：若参考图是竖长条拼接图（`LONG_PAGE`，`H / W >= 2.2`），只在 Prompt 中用文字描述拆解出的单屏版式与光影，**不要传给 `--ref`**；若参考图是单张海报（`SINGLE_POSTER`），可作为 `--ref layout=` 或 `--ref style=` 传入。
2. **借用与隔离边界写死**：在 Prompt 中必须同时写明「从参考图借用什么」和「严禁从参考图复制什么」，防止模型把竞品衣服的领型、颜色或竞品 Logo 带入成图。
3. **6 位 Hex 色值与量化占比**：背景色、次背景色、文字主色、强调色必须写明 `#RRGGBB`；主体占比与留白占比写明具体百分比。
4. **平台排版对齐**：若有画面内文字，必须追加 `VISIBLE_TEXT_BLOCK` 并遵循 `references/typography.md`（例如拼多多使用莫兰迪圆角胶囊 `#EFECE6` + 无描边正体黑体 `#2D2D2D`）。

## 骨架

```text
一张女装电商高转化视觉图（参考图视觉机制迁移）。

【素材角色与隔离契约】
- 成衣图（garment）：唯一商品事实源。服装的所有结构、面料、颜色与图案必须 100% 来自成衣图。
- 模特图（model，若有）：人物五官与眼神光锁定来源。
- 版式/风格参考图（layout / style，若传入）：仅提供构图网格、留白方位与光线色调。
- 隔离禁区（Forbidden from Reference）：严禁复制参考图中的服装款式、领口袖口剪裁、服装颜色、印花图案、参考图模特五官、参考图品牌 Logo 及参考图原有促销文字。

【借用的视觉机制（Deconstructed Visual Mechanics）】
- 构图与机位：<景别：全身 / 七分 / 半身 / 微距>；<机位：平视 / 10° 微俯 / 15° 微仰>；主体位于画面 <居中 / 偏左三分之一 / 偏右三分之一>，主体占画面 <60%–80%>，四周及 <左/右/上> 侧预留 <20%–40%> 呼吸留白。
- 光影与色板（Style Lock）：<主光方向、软硬、色温>；主背景色 <#RRGGBB>，次级色块/胶囊底色 <#RRGGBB>，整体影调通透干净。
- 场景与道具：<极简几何台面 / 柔光棚拍 / 建筑街角 / 原木微景观，仅保留衬托服装的低饱和道具>。
- 排版结构（若为信息图）：<放大镜微距圆窗 / 3 枚极简线性图标列表 / 0.5pt 细线批注引线 / 60:40 不对称分栏>。

【商品事实锁定（Garment Facts Lock）】
- 品类与版型：<从 facts.json 抄：品类、廓形、衣长、肩线>
- 领口 / 袖口 / 下摆 / 门襟：<逐项写清结构与收口方式>
- 颜色与材质：<主色描述 + 表面肌理：哑光棉感 / 垂坠醋酸 / 立体针织纹理>
- 印花与细节：<若有印花，逐字抄写文字、颜色、胸前/后背位置；若无印花，写明“纯色无任何印花与字母”>
- 合理搭配补全：<若为单件上装/下装，写明克制搭配的基础款单品，不抢主商品视觉焦点>

【人物与姿态（若含模特）】
- <年龄段与气质，若传入 model 图则写明五官、眼型、瞳色、双眼皮与模特图一致，头部朝向随本张姿势自然转动>
- <本张具体姿态：自然站立 / 行走抓拍 / 倚靠，双臂自然舒展或垂落，绝对不遮挡胸前、领口与腰线关键设计点>

【镜头质感与反 AI 塑料感】
- <85mm f/2.8 或 50mm 镜头，主商品全清晰对焦，真实织物经纬线与自然重力垂坠褶皱，真实皮肤微纹理>

【VISIBLE_TEXT_BLOCK（仅在需要画面内文字时填写；纯视觉图则写“画面内禁止出现任何文字、水印、角标或 Logo”）】
- 平台排版美学：<如 pinduoduo 清透莫兰迪胶囊轻杂志风 / taobao 暖调轻奢画册风>
- 主标题：「<4–8 字核心主张>」（位置：<留白区>，字色 <#RRGGBB>，正体无描边）
- 副标题/卖点胶囊：「<卖点 1>」「<卖点 2>」（底色 <#RRGGBB>，圆角胶囊，文字左对齐）
- 铁律：仅允许渲染上述「」内的文字；严禁把字重、字号、色号、排版说明等元指令渲染到画面中。
```

## 调用

```bash
forge generate --job-dir <run_dir> \
  --prompt-file <run_dir>/work/prompts/deconstruct-01-layout.txt \
  --ref garment=<成衣图> --ref layout=<单屏参考图> \
  --name deconstruct-01-layout --ratio 3:4 --json
```
