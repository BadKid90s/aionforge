# 换装 Prompt

按 `references/prompts/formula.md` 组段。把下面模板写入 `<product_dir>/prompts/main/<product>-<color>-hero.txt`，把本张姿势 / 机位写进「镜头语言」，把 `facts.json` 里必须锁定的版型 / 印花写进「主体」。比例按计划改 `1:1` 或 `3:4`。

参考图必须带角色名，让文件名成为 garment / model。`garment` 用已通过的 `bg_white`，不要用原始成衣图。调用 [generate](../tools/generate.md)，成品落在 `output/<logo>/main/<product>-<color>-hero.png`。这张通过质检后，才能作为后续姿势图的 `source` 参考。

```
一张女装电商换装图。

【主体】
成衣图（文件名 garment）：衣服本身。常见是平铺、挂拍、白底或人台，没有需要保留的人脸。
这张是输出里整件衣服的唯一标准：版型、领口、肩线、袖型、袖口、下摆、衣长、面料、颜色、印花和文字都以它为准。它不是贴图素材，禁止只把图案贴到模特原来的上衣上。
模特图（文件名 model）：有完整人脸的穿着照片。五官、眼型、瞳色、双眼皮、眼神光、发型发色与模特图为同一人。头、颈、视线必须符合本张姿势（走、坐、回眸、过肩时把头转过去），禁止头部冻结在正面。模特图上原来的上衣整件作废。
（此处粘贴 facts 的领口 / 袖口 / 下摆 / 印花文字。）

【场景】
房间、光线、下装、鞋、包以模特图为准，不要换空间。

【风格（Campaign Style Lock）】
（粘贴 facts.style_lock；为空时粘贴本张 looks.json shot 的【风格】段。必须含 6 位 Hex 色号。）

【镜头语言】
- 景别 / 视角 / 镜头：（本张计划）
- 机位与姿态：（默认复刻模特图原有姿势、机位和手部动作；用户点名换姿势时才改。头必须跟着身体转）

【氛围与细节】
商业女装实拍，真实织物与皮肤微纹理，拒绝塑料磨皮。

【约束】
1. 即使两件衣服颜色或图案相似，也必须按成衣图重做整件衣服。
2. 最容易抄错的三处：袖口、下摆、领口。输出必须与成衣图逐项一致。
3. 图案只出现一次，位置、大小、比例、文字与成衣图一致；成衣图未展示的背面按素色处理。
4. 只输出一张照片，无水印、无边框、无拼图、无额外文字。
5. 用成衣图 / 模特图指代参考图，不要写图序号。
```
