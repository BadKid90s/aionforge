# 换装 Prompt

把下面模板写入 `work/prompts/<name>.txt`，把本张姿势/机位写进文末「补充说明」，把 `facts.json` 里必须锁定的版型/印花也写进去。比例按计划，主图和详情默认 `1:1`。

参考图必须带角色名，让文件名成为 garment / model：

```
forge generate --job-dir <run_dir> --prompt-file <run_dir>/work/prompts/<name>.txt \
  --ref garment=<成衣> --ref model=<模特> --name <name> --ratio 1:1 --json
```

```
# Role: 电商服装虚拟换装师

## 参考图角色（用画面内容区分，不要用先后顺序猜测）

**成衣图**（文件名 garment）：衣服本身。常见是平铺、挂拍、白底或人台，没有需要保留的人脸。
这张是输出里整件衣服的唯一标准：版型、领口、肩线、袖型、袖口、下摆、衣长、面料、颜色、印花和文字都以它为准。它不是贴图素材，禁止只把图案贴到模特原来的上衣上。

**模特图**（文件名 model）：有完整人脸的穿着照片。
这张决定输出里的五官身份、眼部细节、发型发色、肤色、身体姿势、手、下装、鞋、包、房间、光线。头必须跟着本张姿势转，不要把脸钉在正面。这张上原来的上衣整件作废，版型、领口、袖口、下摆、口袋、帽子、面料都不得残留。

区分办法：没有需要保留的人脸、主体是一件衣服的，是成衣图；有完整人脸和身体姿势的，是模特图。

## Goals
1. 输出的衣服必须是成衣图这一件，不是模特图上原来的上衣。
2. 模特是同一个人：五官、眼型、瞳色、双眼皮、眼神光、发型发色不变。头、颈、视线必须符合本张姿势（走、坐、回眸、过肩时把头转过去），禁止头部冻结在正面。

## Rules
1. 即使两件衣服颜色或图案相似，也必须按成衣图重做整件衣服。
2. 最容易抄错的三处：袖口、下摆、领口。输出必须与成衣图逐项一致。
3. 图案只出现一次，位置、大小、比例、文字与成衣图一致；成衣图未展示的背面按素色处理。
4. 只输出一张照片，无水印、无边框、无拼图、无额外文字。

## Workflow
1. 先认出成衣图和模特图。
2. 从成衣图记下版型、领口、肩线、袖口、下摆、面料、颜色、图案。
3. 从模特图只保留人物、姿势、场景、下装和包。
4. 丢掉模特图上的整件上衣，把成衣穿上去。
5. 自检袖口、下摆、领型、肩线、衣长、面料、图案、眼睛是否同一双、头是否跟着姿势。
```
