# 裂变 Prompt

按 `references/prompts/formula.md` 组段。每张单独一份 `<product_dir>/prompts/main/<product>-<color>-<pose>.txt`。**禁止**只写两三句「同一人同一件衣服 + 走两步」。人物和印花从成片抄进【主体】；【场景】【风格】【镜头语言】【主体动作】整段粘贴 `looks.json` 该张 shot。

`source` 必须是本张同色已通过的 `hero`，`garment` 必须是本张同色的 `bg_white`。有姿势参考图时再加 `pose` 角色。调用 [generate](../tools/generate.md)，成品落在 `output/<logo>/main/<product>-<color>-<pose>.png`。

---

## 必填骨架（整段复制后填空）

```
一张女装电商裂变图，可上架实拍，不是插画、不是拼图、不是九宫格。

【主体】
人物锁定（必须写看得见的细节）
- 性别与年龄感：
- 脸型、五官、肤色、妆容：
- 眼型、瞳色、双眼皮、眼神光（眼部细节禁止改）：
- 发型发色长度与分线：
- 体型与肩宽：
以上与成片为同一人。锁的是五官和眼睛，不是把头钉死。头、颈、下颌、视线必须按本张【主体动作】转：侧身看见 3/4 或侧脸，回眸看见侧脸和后脑，走路头朝行进方向，低头看衣时颈前屈。禁止从成片复制一张正面脸贴在脖子上，禁止身体侧了/走了/坐了脸还是证件照。

服装锁定（必须写到印花零件）
- 品类与版型（T恤/卫衣、袖长、衣长、领型、宽松度）：
- 面料颜色与质感：
- 印花位置：
- 印花逐项：主图形 / 颜色 / 文字原文（逐字，含大小写） / 装饰元素：
- 下装、鞋、包（有则锁，没有写「本张不要凭空加」）：
禁止重绘印花、禁止改字、禁止印花出现第二次、禁止换一件衣服。

【本张展示（looks.json 整段粘贴）】
（粘贴本张 shot 的 prompt：【场景】【风格】【镜头语言】【主体动作】【氛围与细节】。不要拆开重写。）
有姿势参考图时加一句：身体、手脚、头朝向以姿势参考图为准，上段文字作补充。

【氛围与细节】
商业女装实拍，皮肤质感真实，衣纹自然。

【参考图角色】
- 成片参考图（文件名 source）：身份、房间、光线、下装、配饰以这张为准。
- 成衣图（文件名 garment，若有）：版型、颜色、印花以这张为准。
用画面内容认图，不要用序号指图。

【约束】
只改机位、姿势和头的朝向，人、衣、房间保持成片。头必须跟本张身体走。只输出一张图。无水印、无边框、无后期大字、无logo角标。
```

---

## 填写规则

1. 先看图再写。人物、印花文字必须来自成片，不准用「一个女生」「一件白T」这种空词。
2. looks 套餐四段整段粘贴，不要改写场景和风格。
3. 印花有字就把原文写进 Prompt，并写颜色。
4. 裂变改镜头、身体动作和头的朝向，不改五官与衣服。
5. 有姿势参考图时加 `pose` 角色，身体和头跟该图。
