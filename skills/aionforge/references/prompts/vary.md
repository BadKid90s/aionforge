# 裂变 Prompt

每张机位单独一份 `work/prompts/<name>.txt`。**禁止**只写两三句「同一人同一件衣服 + 走两步」。必须按下面骨架，把成片里看见的细节全部写进去。

`references/catalog/poses.json` 的 `recipes[].prompt` 只填「本张机位与姿势」那一节，不能代替整份 Prompt。

有成衣图时 `--ref source=` 与 `--ref garment=` 一起传：

```
forge generate --job-dir <run_dir> --prompt-file <run_dir>/work/prompts/<name>.txt \
  --ref source=<参考成片> --ref garment=<成衣> --name <name> --ratio 2:3 --json
```

---

## 必填骨架（整段复制后填空）

```
# Role: 电商女装裂变摄影师

输出一张可上架的实拍电商照片，不是插画、不是拼图、不是九宫格。

## Campaign Style Lock
（从 references/catalog/styles.json 复制选定风格的 style_lock 原文。T恤/卫衣校园默认 campus-youth。）

## 参考图
- 成片参考图（文件名 source）：身份、房间、光线、下装、配饰以这张为准。
- 成衣图（文件名 garment，若有）：版型、颜色、印花以这张为准。

用画面内容认图，不要用序号指图。

## 人物锁定（必须写看得见的细节）
- 性别与年龄感：
- 脸型、五官、肤色、妆容：
- 眼型、瞳色、双眼皮、眼神光（眼部细节禁止改）：
- 发型发色长度与分线：
- 体型与肩宽：
以上与成片为同一人。锁的是五官和眼睛，不是把头钉死。头、颈、下颌、视线必须符合「本张机位与姿势」（回眸看到侧脸、走路头可微动、坐姿可低头看书再抬眼）。禁止换一双眼睛，禁止脸正对镜头而身体在做别的动作。

## 服装锁定（必须写到印花零件）
- 品类与版型（T恤/卫衣、袖长、衣长、领型、宽松度）：
- 面料颜色与质感：
- 印花位置：
- 印花逐项：主图形 / 颜色 / 文字原文（逐字，含大小写） / 装饰元素：
- 下装、鞋、包（有则锁，没有写「本张不要凭空加」）：
禁止重绘印花、禁止改字、禁止印花出现第二次、禁止换一件衣服。

## 场景与光线锁定
- 空间：
- 可见道具（门、灯、桌、窗等）及左右位置：
- 地面材质：
- 主光方向、色温、阴影软硬：
本张仍在同一空间、同一时段。禁止换房间，除非用户明确要求换 references/catalog/scenes.json 里的场景。

## 本张机位与姿势
（粘贴 references/catalog/poses.json 对应配方的 prompt，再补：重心、手、视线、与成片原姿势的差别。）
- 相机高度：
- 水平角度：
- 取景（全身/七分/半身）：
- 身体：
- 手：
- 视线（随姿势，不是永远正视镜头）：
- 头如何转动（与身体动作一致）：
- 与成片的差别（必须有一条明显不同）：

## 画幅
- 比例：
- 服装约占画面：
- 铺满画布，禁止白边、黑边、letterbox。比例不够则扩图延伸场景，不要补空。

## 质量
商业女装实拍，皮肤质感真实，衣纹自然。只输出一张图。无水印、无边框、无后期大字、无logo角标。
```

---

## 填写规则

1. 先看图再写。人物、印花文字、房间道具必须来自成片，不准用「一个女生」「一件白T」这种空词。
2. 「本张机位」至少 4 句：相机 + 取景 + 手脚 + 和成片差在哪。
3. 印花有字就把原文写进 Prompt，并写颜色。
4. 裂变只改机位/姿势/景别，不改人、衣、房。
5. 半身印花图要把印花零件写全；走姿要写脚步哪只在前、手臂怎么摆、印花仍正对镜头。
