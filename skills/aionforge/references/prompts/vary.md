# 裂变 Prompt

按 `references/prompts/formula.md` 组段。每张单独一份 `work/prompts/<name>.txt`。**禁止**只写两三句「同一人同一件衣服 + 走两步」。人物和印花从成片抄进【主体】；【场景】【风格】【镜头语言】【主体动作】整段粘贴 `looks.json` 该张 shot。

有成衣图时 `--ref source=` 与 `--ref garment=` 一起传：

```
forge generate --job-dir <run_dir> --prompt-file <run_dir>/work/prompts/<name>.txt \
  --ref source=<参考成片> --ref garment=<成衣> --name <name> --ratio 2:3 --json
```

---

## 必填骨架（整段复制后填空）

```
一张女装电商裂变图，可上架实拍，不是插画、不是拼图、不是九宫格。

【主体】
人物锁定（必须写看得见的细节）
- 性别与年龄感：
- 脸型、五官、肤色、妆容：
- 眼型、瞳色、双眼皮、眼神光（眼部细节禁止改）：
- 发型发色长度与分线：
- 体型与肩宽：
以上与成片为同一人。锁的是五官和眼睛，不是把头钉死。头、颈、下颌、视线必须符合本张【主体动作】（回眸看到侧脸、走路头可微动）。禁止换一双眼睛，禁止脸正对镜头而身体在做别的动作。

服装锁定（必须写到印花零件）
- 品类与版型（T恤/卫衣、袖长、衣长、领型、宽松度）：
- 面料颜色与质感：
- 印花位置：
- 印花逐项：主图形 / 颜色 / 文字原文（逐字，含大小写） / 装饰元素：
- 下装、鞋、包（有则锁，没有写「本张不要凭空加」）：
禁止重绘印花、禁止改字、禁止印花出现第二次、禁止换一件衣服。

【本张展示（looks.json 整段粘贴）】
（粘贴本张 shot 的 prompt：【场景】【风格】【镜头语言】【主体动作】【氛围与细节】。不要拆开重写。）
有姿势参考图时加一句：身体、手脚、头朝向以姿势参考图为准，上段文字作补充。

【氛围与细节】
商业女装实拍，皮肤质感真实，衣纹自然。

【参考图角色】
- 成片参考图（文件名 source）：身份、房间、光线、下装、配饰以这张为准。
- 成衣图（文件名 garment，若有）：版型、颜色、印花以这张为准。
用画面内容认图，不要用序号指图。

【约束】
只改机位和姿势，人、衣、房间保持成片。只输出一张图。无水印、无边框、无后期大字、无logo角标。
```

---

## 填写规则

1. 先看图再写。人物、印花文字必须来自成片，不准用「一个女生」「一件白T」这种空词。
2. looks 套餐四段整段粘贴，不要改写场景和风格。
3. 印花有字就把原文写进 Prompt，并写颜色。
4. 裂变只改本张展示里的镜头与动作，不改人、衣。
5. 有姿势参考图时 `--ref pose=`，身体跟该图。
