# 印花提取 Prompt

按 `references/prompts/formula.md` 组段。把下面模板写入 `work/prompts/<name>.txt`。用户指定了哪一块印花时，把要求写进「主体」。

然后：

```
forge generate --job-dir <run_dir> --prompt-file <run_dir>/work/prompts/<name>.txt \
  --ref <商品照片> --name print --cutout --json
```

`--cutout` 把白底打成透明并按图案裁切，这是本地处理，不是模型能力。

```
一张可复用的平面印花图案文件。

【主体】
从参考图（服装或商品照片）上提取印花。形状、颜色、文字和比例必须与参考图一致，不要重新设计、美化或补全。把图案放平，去掉衣服褶皱和透视。多块时提取正面面积最大的一块（用户另有指定则按指定）。

【场景】
纯白 `#FFFFFF` 背景，图案完整居中，四周少量白边。

【风格（Campaign Style Lock）】
平面图形，无光影、无材质褶皱。

【镜头语言】
正面平面图，无透视。

【氛围与细节】
文字和描边完整，边缘干净。

【约束】
不要输出衣服、模特、衣架、吊牌、背景杂物或水印。只输出一张图片，不要拼图，不要添加说明文字。
```
