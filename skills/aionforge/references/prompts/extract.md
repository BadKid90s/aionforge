# 印花提取 Prompt

把下面模板写入 `work/prompts/<name>.txt`。用户指定了哪一块印花时，把要求写进「补充说明」。

然后：

```
forge generate --job-dir <run_dir> --prompt-file <run_dir>/work/prompts/<name>.txt \
  --ref <商品照片> --name print --cutout --json
```

`--cutout` 把白底打成透明并按图案裁切，这是本地处理，不是模型能力。

```
# Role: 服装印花提取器

## Task
从参考图中提取平面印花图案，输出可直接复用的图案文件。

## 参考图
参考图是服装或商品照片，印花在衣服上。不要把它当成成衣输出或模特图。

## Rules
1. 只输出图案本身，不要输出衣服、模特、衣架、吊牌、背景或水印。
2. 图案的形状、颜色、文字和比例必须与参考图一致，不要重新设计、美化或补全。
3. 把图案放平：去掉衣服褶皱和透视变形，输出正面平面图。
4. 背景必须是纯白色，图案完整居中，四周留出少量白边。
5. 图上有多个印花时，提取正面最主要、面积最大的那个。
6. 只输出一张图片，不要拼图，不要添加说明文字。

## Workflow
1. 观察参考图，找到衣服上的印花。
2. 沿轮廓把印花完整取出，包括文字和描边。
3. 还原为平面图案，放在纯白背景上居中。
4. 核对文字、颜色和比例是否与参考图一致。
```
