# 印花提取 Prompt

## 平面 logo 图案稿

优先用 [cutout](../tools/cutout.md) 的 AI 清洗模式（先模型清洗白底，再本地抠图）。模型只负责语义判断：去掉图案外围的白底、白边、白色残留和半透明白色光晕，保留图案内部的白色文字、描边和高光；最终透明通道由本地 flood fill 生成，不依赖模型直接输出透明图。原稿本来就是干净透明 PNG 时，关闭 AI 清洗，只走本地抠图，文字和形状逐像素不变。

深色图案、字母孔洞里的封闭白区打开「清理封闭白区」；白色字标保持「保留封闭白区」。稿子有压缩噪点或孤立白点时开启去噪（约 4px）。提取后用 [verify](../tools/verify.md) 的印花检查。

图案内部有透明镂空（字母内圈、图形穿孔）或图案本身就是白色时，不要用 AI 清洗模式：模型会把镂空当成白色细节保留，纯白图案可能被清洗成空白。这两类稿子走本地路径。

调用 [cutout](../tools/cutout.md) 的 AI 清洗模式执行。AI 清洗生成的 Prompt 自动落在 `<product_dir>/prompts/refs/<name>-clean.txt`。

```
一张可复用的平面印花图案文件。

【主体】
把参考图中的平面印花图案完整提取到纯白背景上。形状、颜色、文字、字体、笔画、比例和相对位置必须与参考图一致，逐字保留，不要重新设计、美化、补全、简化或改字。

【场景】
纯白 `#FFFFFF` 背景，图案完整居中，四周少量白边。

【风格（Campaign Style Lock）】
平面图形，无光影、无材质褶皱。

【镜头语言】
正面平面图，无透视。

【氛围与细节】
去掉图案外围的白色背景、白边、白色残留和半透明白色光晕；保留图案内部本来就属于设计的白色（白色文字、描边、高光、眼睛留白）。边缘干净。

【约束】
不要输出衣服、模特、衣架、吊牌、背景杂物，也不要添加新的水印、二维码或说明文字。只输出一张图片，不要拼图。源图带素材站水印时，提示用户换有授权的无水印源文件。
```
