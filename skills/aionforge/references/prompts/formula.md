# 生图 Prompt 组成公式

所有工作流写 `<product_dir>/prompts/<bucket 或 store>/<name>.txt` 时按本公式组段。工作流模板只填本任务槽位，不要另起一套结构。

对齐：

- 阿里云文生图进阶公式：主体（主体描述）+ 场景（场景描述）+ 风格 + 镜头语言 + 氛围词 + 细节修饰
- OpenAI Academy《Creating images with ChatGPT》：先写用途，再写主体、正在发生的事、地点、风格；光线与构图要具体；约束直接写死；图内文字放进引号并标明字体/位置/颜色

电商出图必须把商品事实锁进「主体」，把禁区锁进「约束」。不要写成 1–3 句散文——领口袖口印花文字一松，模型就会改款。

## 组段顺序（固定）

| 段 | 写什么 | 来源 |
| --- | --- | --- |
| 用途 | 一张什么电商图、回答哪个买家问题 | 计划 `goal` / 图型 id |
| 主体 | 衣服结构、颜色、面料、印花逐字；有人则写五官与姿势动作 | `facts.json` + 成衣图 / 模特图 / 成片 |
| 场景 + 风格 + 镜头语言 + 主体动作 | 万象进阶公式，四段写在同一套餐 shot 里 | `catalog/looks.json`；有姿势参考图时加 `--ref pose=` |
| 氛围与细节 | 质感、织物经纬、皮肤微纹理、主光软硬 | `anti_ai_tips`、成片光线 |
| 参考图角色 | 每张图只承担一个角色，用成衣图/模特图等称呼 | `--ref` 角色名 |
| 图内文字 | 有字才写 `VISIBLE_TEXT_BLOCK`，文案用「」包裹 | `typography.json` |
| 约束 | 不准出现的东西、不准改的东西 | 工作流红线 + `facts.uncertain` |

`forge generate` 没有独立 `negative_prompt` 参数，负向内容写进「约束」段。

## 镜头语言词典（电商常用）

写「镜头语言」时用下面的词，不要只写「好看的构图」。

| 维 | 选用 |
| --- | --- |
| 景别 | 特写 / 近景 / 中景 / 七分身 / 全身 / 远景 |
| 视角 | 平视 / 微俯 10° / 微仰 15° / 俯视 |
| 镜头 | 85mm 人像 / 50mm 标准 / 微距 / 中长焦虚化背景 |

## OpenAI 侧必须遵守的写法

- 光线写具体方向：`左侧窗来的柔和自然光`，不要写 `美丽的光线`。
- 编辑或裂变写死不变项：`只改机位和姿势，人、衣、房间保持成片`。
- 图内文案短、放进「」，并写字体风格、颜色 Hex、位置。
- 用「成衣图 / 模特图 / 印花图 / 锚点成片」指代参考图，不要写「图1 / 图2」。

## 填空骨架

所有工作流模板都输出这一形：

```
一张女装电商视觉图：<用途>。

【商品事实锁定（Garment Facts Lock）】
- …

【场景】
- …

【风格（Campaign Style Lock）】
- …

【镜头语言】
- 景别 / 视角 / 镜头：
- 画面占比与留白：
- 机位与姿态：

【氛围与细节】
- …

【参考图角色与隔离契约】
- …

【VISIBLE_TEXT_BLOCK】
- …

【约束】
- 只输出一张照片。无水印、无边框、无拼图。
- 未知部位不要臆造。
```
